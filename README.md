# Ranek 🛍️

Projeto desenvolvido durante o curso de **React da Origamid**, com a implementação de uma plataforma de produtos utilizando React.

🔗 **[Demo](https://react-ranek-two.vercel.app/)**

## 🚀 Tecnologias

* React
* JavaScript
* React Router
* Vite
* CSS
* Fetch API

## 📚 Conceitos praticados

* Componentização e modularização
* React Hooks
* Custom Hook `useFetch`
* Consumo de API com Fetch
* React Router
* Rotas dinâmicas
* Modularização de estilos
* Renderização condicional

## 🎓 Curso

Projeto desenvolvido como parte do curso **React Completo** da [Origamid](https://www.origamid.com/).
